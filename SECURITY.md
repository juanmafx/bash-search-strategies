# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier, unversioned code | No |

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise, open an issue that asks for a private contact channel and leaves out the technical details.

## Scope

This is a local command-line tool. It opens no network connections and handles no credentials. Its random generator is for reproducible experiments and is not cryptographically secure.
